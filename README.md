# 국내 학회 진료지침 모음

대한의학회 회원학회 홈페이지 게시판에 공개된 진료지침을 매일 자동으로 모아, 날짜별·분과별·학회별로 찾아볼 수 있게 정리한 색인 사이트입니다.

학회마다 진료지침을 올리는 위치와 형식이 제각각이고, 대한의학회 임상진료지침 정보센터에도 모든 지침이 올라오지는 않습니다.
이 사이트는 학회 게시판을 직접 확인해 공개된 국문 진료지침을 한곳에서 볼 수 있게 하는 것을 목표로 합니다.

## 기능

- **날짜별, 분과별, 학회별** 보기와 계열·분과·학회·기간 필터, 제목 검색
- 여러 학회가 함께 발표한 같은 지침은 한 항목으로 합쳐서 보여줍니다.
- 최근 30일 안에 새로 수집된 지침에는 **NEW** 표시가 붙고, RSS(`feed.xml`)로 신규 지침 알림을 받을 수 있습니다.
- **수집 현황** 탭에서 학회별 수집 상태를 볼 수 있습니다.
- 필터 상태가 주소에 남으므로, 주소를 공유하면 같은 화면이 열립니다.

## 수집 범위

- 현재 내과 및 내과 분과학회 29곳을 대상으로 합니다 (`config/societies.yaml`). 외과계 등은 순차적으로 추가할 예정입니다.
- 공개 게시물만 수집합니다. 로그인이 필요한 회원 전용 게시물과 첨부파일은 수집하지 않습니다.
- 게시물 제목, 날짜, 원문 게시물 링크, 첨부파일 링크만 저장합니다. 지침 원문은 이 저장소에 복제하지 않습니다.

## 동작 방식

```
config/societies.yaml   수집 대상 학회와 게시판 주소
config/taxonomy.yaml    계열·분과 분류
gcrawler/               수집기 (Python)
site/                   웹 화면 (HTML/JS)
data/                   수집 결과
.github/workflows/      매일 수집 → GitHub Pages 배포
```

1. GitHub Actions가 매일 새벽(KST) 각 학회의 진료지침 게시판을 확인합니다. 게시판 주소가 등록되지 않은 학회는 홈페이지 메뉴에서 진료지침 게시판을 찾습니다.
2. 게시판 엔진이 학회마다 달라도 읽을 수 있도록 범용 목록 파서를 쓰고, 필요한 경우 학회별 설정이나 맞춤 파서(`gcrawler/adapters/`)로 보완합니다.
3. 새 게시물은 상세 페이지를 열어 공개 여부와 게시일을 확인합니다. 날짜는 게시판 목록, 상세 페이지, 제목에 적힌 연도, 수집일 순으로 정합니다.
4. 결과는 `data/`에 커밋되어 이력이 남고, 정적 사이트로 빌드되어 배포됩니다.

## 수집 원칙

- 각 사이트의 `robots.txt`를 따르며, 같은 사이트에는 최소 1.5초 간격으로 요청합니다. 자동 접속 차단 장치는 우회하지 않습니다.
- 상세 페이지는 새 게시물만, 학회당 하루 정해진 횟수 안에서 확인합니다.
- 진료지침의 저작권은 각 학회에 있습니다. 이 사이트는 원문으로 안내하는 색인이며, 내용은 반드시 원문으로 확인해 주세요.
- 학회에서 수집 제외를 요청하면 바로 반영합니다. Issue로 알려 주세요.

## 학회 추가·수정

누락된 학회나 잘못 읽히는 게시판이 있으면 Issue나 Pull Request로 알려 주세요.
학회는 `config/societies.yaml`에 아래 형식으로 추가합니다.

```yaml
- id: ksxx                    # 영문 고유 ID
  name: 대한OO학회
  short: OO학회
  homepage: https://www.example.or.kr
  group: 내과계                # 계열
  specialty: 내과              # 전문과
  division: 소화기             # 분과
  boards:                     # 비워 두면 홈페이지에서 자동 탐색
    - url: https://www.example.or.kr/bbs/list.php?code=guide
      name: 진료지침
      dedicated: true         # 진료지침 전용 게시판이면 true
```

robots.txt나 웹 방화벽 때문에 자동 수집이 막힌 학회(`manual: true`)는 `config/manual.yaml`에 공개 진료지침을 직접 적어 등록합니다.
사이트에서는 학회 배지에 ✎ 표시가 붙습니다.

로컬에서는 다음 명령으로 확인할 수 있습니다.

```bash
pip install -r requirements.txt
python -m gcrawler check ksxx   # 해당 학회 게시판을 어떻게 읽는지 미리 보기 (저장 안 함)
python -m gcrawler crawl        # 수집
python -m gcrawler build        # _site/ 에 사이트 생성
python -m pytest -q             # 테스트
```
